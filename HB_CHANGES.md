Base: cabaletta/baritone branch `26.2` at `9fadf7cf` (tag v1.19.0, Minecraft 26.2).

Keep this diff small. Every change made on top of upstream is listed here, newest last, with the
files it touches. Baritone is LGPL-3.0: if the fork is distributed, its source must be too.

Planned for Phase 4 (from the build spec):

- Movements wait until the crosshair actually reaches the target before breaking or placing. (Largely
  upstream behavior already: movements ask to break only while `ctx.isLookingAt` the block, and with an
  intent sink set the crosshair is the real one.)
- Looser movement timeouts and stuck detection for human pacing.
- Target-selection override in the mine process (ores) for the mining-order model; the build process is #4.
